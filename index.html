Recycle PET bottles and aluminum cans. Earn points and get Wi-Fi vouchers.

Open ARVY Download ARVY (Android)

Android phones and tablets only.

How to install

  1. Tap Download ARVY above.
  2. When the download finishes, open the file from your notifications or Downloads folder.
  3. If Android asks, allow installs from this browser. The option name varies by phone.
  4. Tap Install, then Open.
